# Валютный калькулятор

«Валютный калькулятор» — одностраничное приложение, которое показывает курсы валют Банка России, полученные через сервис cbr-xml-daily.ru, позволяет выбирать дату и изменять набор отображаемых валют. В приложении можно конвертировать суммы по курсам ЦБ РФ. Кросс-курсы между иностранными валютами рассчитываются через российский рубль.

## Возможности

- отображение USD, EUR и CNY по умолчанию;
- добавление и удаление валют из набора карточек;
- выбор архивной даты курса;
- конвертация между любыми загруженными валютами и RUB;
- обмен исходной и целевой валют местами одной кнопкой;
- адаптивный интерфейс для desktop, tablet и mobile;
- понятные состояния загрузки и обработка ошибок получения данных.

## Источник данных

Курсы загружаются с сервиса [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/).

Для выбранной даты используется архивный URL следующего формата:

```text
https://www.cbr-xml-daily.ru/archive/ГГГГ/ММ/ДД/daily_json.js
```

## Формула расчёта

Курс одной единицы валюты определяется с учётом номинала:

```text
курс одной единицы = Value / Nominal
```

Любая конвертация выполняется через рубль:

```text
сумма в рублях = сумма × курс исходной валюты
результат = сумма в рублях / курс целевой валюты
```

Для RUB используются `Value = 1` и `Nominal = 1`.

## Локальный запуск в Windows

Откройте PowerShell и перейдите в папку проекта:

```powershell
Set-Location C:\Projects\currency-calculator
```

Запустите встроенный HTTP-сервер Python:

```powershell
python -m http.server 8000
```

Если команда `python` недоступна, используйте Python Launcher:

```powershell
py -m http.server 8000
```

После запуска откройте страницу:

```text
http://localhost:8000/
```

## Краткое объяснение для преподавателя

При открытии страницы приложение устанавливает текущую дату и загружает архив курсов через Fetch API. Для другой даты адрес архивного файла формируется из года, месяца и дня. Поле `Nominal` учитывается, потому что значение `Value` может быть указано сразу за несколько единиц валюты. Сначала сумма переводится в рубли по курсу `Value / Nominal`, а затем из рублей в целевую валюту. Если запрос завершается ошибкой, старые данные очищаются и пользователь видит понятное сообщение. Локальный HTTP-сервер используется, чтобы открывать проект по протоколу HTTP, а не напрямую через file://. Это обеспечивает предсказуемую загрузку файлов и выполнение запросов Fetch API.
